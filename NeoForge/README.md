# Auto-Shield Reborn - NeoForge (Minecraft 26.1 - 26.1.2)

**NeoForge** builds of Auto-Shield Reborn for the Minecraft 26.1 - 26.1.2 line. Client + server mod (server-authoritative).
Standalone - no Architectury, no `common/` subproject.

## Builds

| Version | Minecraft | Java | Toolchain |
| --- | --- | --- | --- |
| [`26.1.2/`](26.1.2) | 26.1.2 | 25 | ModDevGradle (MDG), NeoForge 26.1.2 |

## Build

```
cd <version>
./gradlew build      # Windows: .\gradlew.bat build
```

Output: `build/libs/autoshield-reborn-*.jar`. Part of the [`26.1` branch](https://github.com/Kishku7/autoshield-reborn/tree/26.1).

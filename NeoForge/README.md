# Auto-Shield Reborn - NeoForge (Minecraft 26.2 (pre-release))

**NeoForge** builds of Auto-Shield Reborn for the Minecraft 26.2 (pre-release) line. Client + server mod (server-authoritative).
Standalone - no Architectury, no `common/` subproject.

## Builds

| Version | Minecraft | Java | Toolchain |
| --- | --- | --- | --- |
| [`26.2/`](26.2) | 26.2 (pre-release) | 25 | ModDevGradle (MDG), built vs a NeoForge 26.2 alpha |

## Build

```
cd <version>
./gradlew build      # Windows: .\gradlew.bat build
```

Output: `build/libs/autoshield-reborn-*.jar`. Part of the [`26.2` branch](https://github.com/Kishku7/autoshield-reborn/tree/26.2).

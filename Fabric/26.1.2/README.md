# Auto-Shield Reborn - Fabric 26.1.2 (Minecraft 26.1 - 26.1.2)

Builds the **Fabric** jar for **Minecraft 26.1 - 26.1.2**. Client + server mod (server-authoritative; dedicated-server safe).

- Loader: Fabric
- Minecraft: 26.1 - 26.1.2
- Java: 25
- Toolchain: fabric-loom (mojmap-native, no Architectury)

## Build

```
./gradlew build      # Windows: .\gradlew.bat build
```

Output: `build/libs/autoshield-reborn-*.jar`

## Dependencies

- **Fabric API** - required.
- **ModMenu** - optional (config screen).

Part of the [`26.1` branch](https://github.com/Kishku7/autoshield-reborn/tree/26.1). [Modrinth](https://modrinth.com/mod/autoshield-reborn) - [Releases](https://github.com/Kishku7/autoshield-reborn/releases).
